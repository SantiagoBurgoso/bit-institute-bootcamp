# Mini Store - MEAN Stack Final Project

## Project Description

Mini Store is a full-stack product management application developed using the MEAN Stack.

## Technologies

- MongoDB and MOngoose
- Express.js
- Angular
- Node.js
- JWT
- bcrypts
- express-validator

## Features 

- User registration and login
- JWT authentication
- Input validation
- Create products
- View products
- View individual product details
- Update products
- Delete products
- Responsive design

## Database Models

- User
- Product

## Backend Installation

1. Open the backend folder.
2. Run npm install.
3. Configure the .env file.
4. Run npm run dev.

Backend: http//localhost:3000

## Frontend Installation

1. Open the frontend folder.
2. Run npm install.
3. Run npm start.

Frontend: http://localhost:4200

## API Endpoints

POST /api/auth/register
POST /api/auth/login
GET /api/auth/me

GET /api/products
GET /api/products/:id
PODT /api/products
PUT /api/products/:id
DELETE /api/products/:id
